幕后账本 · Colophon

源自古希腊语 “kolophon”（顶峰/收尾）。传统印刷中用于记录书籍的排印与装帧信息；在数字世界，它记录这座赛博小岛的工程底座。

核心引擎与框架
Astro 5 + React 19

拥抱静态生成（SSG）与局部岛屿架构（Islands Architecture），全站近乎 0 运行时 JS 消耗。

样式与视觉系统
Tailwind CSS v4 (Pure CSS Next-gen engine)

基于 Tailwind CSS v4 原生引擎，辅以克制雅致的 Zinc 中性色盘与纸质物理微噪点。

字体与排版
Inter / Geist / JetBrains Mono / 思源宋体

代码等宽采用 JetBrains Mono，正文无缝支持现代无衬线与人文思源宋体一键双模切换。

检索与离线搜索
Pagefind 1.5 (静态毫秒级离线全文索引)

Pagefind 本地静态多语言索引，按 ⌘K 毫秒级匹配，无需维护沉重的 Elasticsearch 或 Algolia 服务。

转场与动效
ParticleX Aurora Flow + View Transitions

ParticleX 灵感柔和极光流体光晕、卡片物理悬浮感知与原生 Astro View Transitions 无缝路由切页。

部署与许可
Docker Multi-stage + Nginx Alpine · MIT / 知识共享 CC BY-NC-SA 4.0

预置极速 Alpine 镜像与 Waline 独立容器编排；代码遵循 MIT，原创内容遵循 CC BY-NC-SA 4.0。

工程与设计底线

本站坚持「克制、透明与长期主义」：不收集任何访客追踪 Cookie，不接入侵入式第三方分析脚本，完全依赖离线与本地优先能力。
